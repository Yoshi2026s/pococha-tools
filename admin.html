ADMINISTRATION

ツールの公開設定

ツールごとに、この広場への掲載を切り替えられます。

「非公開」はこの広場からの非表示です。リンク先ツールの利用や、公開リポジトリのソースへのアクセスは制限しません。リンク先の停止・認証が必要な場合は、各ツール側で設定してください。

管理者認証

Yoshi2026sのGitHubトークンで認証します。トークンはGitHub APIへの通信にだけ使用し、このタブを閉じると破棄します。

初回の設定方法
  1. GitHubでFine-grained tokenを作成 ↗
  2. Resource ownerはYoshi2026s。Repository accessは「Only select repositories」で「pococha-tools」だけを選択します。
  3. Repository permissionsの「Contents」を「Read and write」に設定し、短い有効期限を選んで発行します。
  4. トークンを上の欄に入力します。チャットやソースコードへ貼り付けないでください。

トークンを使わず管理する場合は、GitHubの編集画面 ↗で各ツールのpublicをtrue（公開）／false（非公開）に変更してコミットできます。GitHubへのログインと書き込み権限が必要です。

掲載状態

ボタンを押すと保存します。公開ページへの反映には通常1〜数分かかります。
