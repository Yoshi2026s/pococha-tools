# ポコツール広場

Yoshi2026sのPococha関連ツール6件をまとめた、スマートフォン対応のリンク集です。

公開先（Pages設定後）: https://yoshi2026s.github.io/pococha-tools/

管理画面: https://yoshi2026s.github.io/pococha-tools/admin.html

## 公開

GitHub PagesのSettings → Pages → Build and deploymentで、Sourceを「Deploy from a branch」、Branchを「main」、フォルダを「/(root)」にして保存します。ビルド不要です。公開ファイルのみをリポジトリに入れ、テスト・作業用ファイルは含めていません。

## 一般公開・非公開の切り替え

管理画面でYoshi2026sのFine-grained personal access tokenを入力し、「管理者として認証」を押します。各ツールの「一般公開 / 非公開」ボタンを押すと、tools.jsonがGitHub Contents APIでコミットされ、Pages再公開後に全訪問者の表示へ反映されます。通常1〜数分かかります。開いたままの公開ページは再読み込みしてください。

トークンの設定:

- Resource owner: Yoshi2026s
- Repository access: Only select repositories → pococha-toolsのみ
- Repository permissions: Contents → Read and write（Metadataは自動でRead）
- 短い有効期限を推奨。トークンはチャットやリポジトリへ保存しないでください。

トークンはJavaScriptのメモリ上だけで保持し、localStorage/sessionStorage/Cookieへ保存しません。GitHub APIのAuthorizationヘッダーにだけ送ります。ログアウト・ページ離脱で破棄します。第三者スクリプトや解析ツールは使用していません。管理画面はYoshi2026s本人かつリポジトリのadmin権限を確認します。書き込みの認可そのものはGitHub APIが担当します。このリポジトリの書き込み権限も管理者だけに保持してください。書き込み権限を持つ共同作業者はGitHubで直接設定を変更できます。

トークンを作らない場合は、GitHubにログインしてtools.jsonを直接編集し、各ツールのpublicをtrue（公開）/false（非公開）にしてコミットする方法もあります。

SHA照合で同時編集の上書きを拒否します。保存が失敗した場合は最新版を再取得し、取得できなければログアウトします。未認証の訪問者には管理操作を表示しません。管理画面のURL自体を隠すことで認証を代用していません。

## 非公開の意味

ここでの「非公開」は、このリンク集からの非表示です。リンク先アプリへの直接アクセスや、公開リポジトリのtools.json・Git履歴の閲覧を制限しません。リンク先自体を非公開にするには、各サービス側に認証・アクセス制限が必要です。

## ローカル確認

リポジトリのフォルダで `python -m http.server 8000 --bind 127.0.0.1` を実行し、http://127.0.0.1:8000/ を開きます。JavaScriptが必要です。外部パッケージ・ビルド・サーバー側秘密鍵は不要です。

Pococha非公式のファン制作ツール集です。

## 画面サムネイルとスマートフォン表示

各カードに実際の公開ツール画面の一部を表示します。画像は `assets/thumbnails/` のWebPで、撮影時の静止画です。表示中の実績や日時をリアルタイムに示すものではありません。差し替え時は画像ファイルとtools.jsonのthumbnailを更新します。検索・管理者による掲載状態の切り替えでも画像を含むカード全体が対象です。

スマートフォンは1列、横幅に合わせた16:9画像、説明14px、検索欄16px、44px以上の操作領域を使います。上部の装飾は非表示にしてツール一覧への移動を短くしています。画像は軽量なWebPとし、2件目以降は遅延読み込みします。

### プライバシーに配慮した撮影

ゲーム2件はタイトルではなく、ローカルの実ゲームを新規プレイして撮影した画面です。主人公・ヒロイン・プレイヤー・CPUは架空名で設定しています。ポコログは同じ実UIに架空の配信者名・応援者名と合成サンプル数値を入れて撮影しています。元ツールの共有データは読み書きしていません。

該当カードには「架空名のデモ画面」と表示します。個人名のないメーター・解答・図鑑の画像も目視確認しています。撮影用のローカルソースはこの公開リポジトリには含めません。画像差し替え時は新しいファイル名も使い、閲覧者が古い画像を継続表示しにくくしています。

## 複数の画面プレビュー

検索・コピー・メモ・設定・ゲーム内機能など、用途の違う画面を各ツールに10枚ずつ、計60枚を登録しています。画像部分は左右スワイプ・左右ボタン・キーボードの左右矢印 / Home / Endで操作でき、自動送りは行いません。枚数表示とドットで現在位置を示し、画面回転後も選択中の画像を維持します。画像操作から誤って外部ページが開かないよう、ツールへのリンクはツール名と「ツールを開く」ボタンに置いています。

tools.jsonの各ツールのpreviews配列で画像のsrcとcaptionを管理します。現在は10枚、各ツール10枚まで対応しています。画像を増やす場合も個人名・実記録が含まれないことを確認してください。


## スマホでの使いやすさ

スマホでは2列で表示し、6ツールを3段にまとめています。カードの余白や画像操作の配置を詰め、説明文は省略せず、画像タップによる拡大と44px以上の操作ボタンを維持しています。

- ツール名と説明を画像より先に表示し、「ツールを開く」は大きなボタンにしています。
- 検索・カテゴリ・ツール選択は上部に残り、長い一覧でも探し直せます。高さの少ない横向き画面では固定を解除します。
- 画像のタップまたは「拡大」でプレビューを開き、100 / 150 / 200 / 300％に拡大できます。拡大後は上下左右にスクロールできます。
- 拡大画面でも前後の画像へ移動でき、閉じると同じ画像の位置へ戻ります。キーボードの左右 / Home / End、Escape、Tabにも対応しています。
- メイン操作は44px以上のタップ領域を確保し、検索・認証欄は16pxの文字を使っています。各ツール10枚のプレビューと架空名の表示は維持しています。

320 / 360 / 390 / 430px幅、タブレット、PC、横向き画面で表示を確認しています。管理者認証・公開切り替え・更新競合の既存チェックも通過しています。

表示例：[スマホの2列一覧](docs/mobile-two-columns.webp) / [画像の200％拡大](docs/mobile-upgrade-zoom.webp)


## ホーム画面のアイコン

公開ページにはiPhone向けのapple-touch-icon（180px）と、Android向けのWeb App Manifest（192px / 512px）を設定しています。既存のPロゴをPNGへ書き出し、背景を不透明にしています。512px版は丸型などのマスクでも文字が欠けない安全領域に収めています。

- 表示名：ポコツール（正式名：ポコツール広場）
- 起動先・スコープ：このリポジトリの公開ページ `/pococha-tools/`
- iPhone：Safariの共有メニューから「ホーム画面に追加」
- Android：Chromeのメニューから「ホーム画面に追加」

すでに追加したショートカットのアイコンが古い場合は、公開ページから追加し直してください。
